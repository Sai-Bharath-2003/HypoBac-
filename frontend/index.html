About HypoBac

Hypothetical bacterial protein classification using machine learning · Bioclues collaboration

What is HypoBac?
HypoBac is a database of hypothetical proteins (HPs) identified in bacterial genomes — proteins that exist in the genome sequence but have no experimentally confirmed function.

Using the WEKA machine learning framework, each HP is scored across 7 bioinformatics criteria and classified as pathogenic (CLASS=1) or non-pathogenic (CLASS=0).

Protein data is fetched live from the UniProt REST API and cached locally, giving researchers real-time access to organism names, domain annotations, and FASTA sequences.
The 7 WEKA Criteria
C1 Protein Family Score — matches a known protein family
C2 Orthology Score — has orthologs in other organisms
C3 Protein Interaction Score — participates in known PPIs
C4 BBH Score — Best Bidirectional BLAST Hit confirms homology
C5 Sorting Signal Score — has signal peptide or motif
C6 Linked to Pseudogenes — connected to pseudogene regions
C7 Homology Modelling Score — 3D structure can be modelled

CLASS=1 (206 proteins) = predicted pathogenic
CLASS=0 (108 proteins) = predicted non-pathogenic
⚡ BLAST Integration — 3 Approaches (planned)
1
NCBI BLAST REST API (recommended) — Free, no installation. User pastes a sequence, backend submits a job to blast.ncbi.nlm.nih.gov/blast/Blast.cgi, polls every 5s until complete, returns hits. Best for: web-based search against the full NR database. Limitation: slow (30–120s per search).
2
Local BLAST against HypoBac sequences — Install BLAST+ locally, build a database from the 1000+ HypoBac FASTA sequences. Search runs in <2s. Best for: fast in-portal searches against only our protein set. Limitation: needs BLAST+ installed on the server, and FASTA sequences pre-downloaded.
3
BioPython BLAST wrapper — Python library that wraps the NCBI BLAST API cleanly. Simplest to code, same speed as option 1. Best for: quick integration with minimal new code. We would add one new Flask route POST /api/blast that accepts a sequence and returns hits with e-value, identity %, and alignment.
Recommended: Start with Approach 3 (BioPython) for the backend route, then upgrade to Approach 2 (local BLAST) once FASTA sequences are downloaded. The frontend BLAST button below is already wired — just needs the backend route.
